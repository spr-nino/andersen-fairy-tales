# 安徒生童话故事阅读网站

这是一个无框架的静态安徒生童话阅读网站。项目不依赖 Node.js、npm 或构建工具，直接使用浏览器即可运行。

## 启动方式

### 方式一：直接打开

在文件管理器中双击项目根目录下的 `index.html`，或右键选择浏览器打开即可。

### 方式二：使用本地静态服务器（推荐）

在项目目录打开 PowerShell，执行：

```powershell
python -m http.server 8080
```

然后在浏览器访问：

<http://localhost:8080>

如果电脑上使用的是 `py` 命令，也可以执行：

```powershell
py -m http.server 8080
```

停止服务时，在 PowerShell 窗口按 `Ctrl + C`。

## 项目结构

```text
儿童故事网页/
├─ index.html        # 阅读页结构与统一故事数据
├─ app.css           # 首页、收藏、足迹、搜索等共享样式
├─ app.js            # 路由、视图和阅读交互
├─ storage.js        # 收藏、足迹与偏好存储服务
├─ search.js         # 故事搜索与排序工具
├─ tests.html        # 可直接运行的轻量浏览器测试
├─ tests.js          # 存储和搜索测试用例
├─ README.md         # 项目说明与启动方式
└─ .claude/          # 本地开发配置（如有需要）
```

## 使用说明

- 首页、故事阅读、我的收藏、阅读足迹和搜索使用 Hash 路由，支持浏览器前进、后退与子页面刷新。
- 可通过左侧书架切换故事，并使用底部工具栏翻页、收藏、调整字体、切换夜间模式和朗读。
- 收藏、阅读位置和界面偏好保存在浏览器 `localStorage`；清除站点数据后会恢复初始状态。
- 访问 `/tests.html` 可运行存储容错、收藏去重、进度边界与搜索匹配测试。
- 页面引用了 Google Fonts；如果网络受限，浏览器会自动回退到系统中文字体。

## 浏览器建议

建议使用最新版 Chrome、Edge、Firefox 或 Safari。使用本地静态服务器访问时，浏览器的资源加载和本地存储行为会更稳定。
